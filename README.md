## Documentation Standard

Each project writeup includes:

- Overview of the problem and security context
- Tools and environment used
- Key concepts demonstrated
- Implementation or lab steps
- Results, outputs, or screenshots where useful
- Lessons learned and next improvements

## Ethics

All work in this repository is for learning, defensive security, and authorized lab environments only. I do not test systems without permission.
